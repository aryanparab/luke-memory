# Provenance and scope

Luke Memory is a focused continuation by Aryan Parab of the memory-assistant idea
from the collaborative Luke-os hackathon project:

- Original project: https://github.com/geradivij/Luke-os
- Aryan's existing fork: https://github.com/aryanparab/Luke-os
- Original team listed in the project: Aryan, Arshia, Divij, and Vraj.

The original MIT license and copyright notice are preserved in LICENSE. This
repository reorganizes the memory concept into a smaller Electron/Flask app,
with SQLite persistence, full-text search, explicit capture controls, and tasks.
It is not a claim of sole authorship of the original team project.

The attention/stress agent, webcam/emotion analysis, keyboard/mouse tracking,
clipboard interception, productivity scoring, focus enforcement, voice coaching,
and counselor features are outside this repository's scope.
